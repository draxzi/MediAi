# MediAI

AI-powered health intelligence platform for instant symptom assessment and personalized wellness guidance.

## Live Demo
https://askmediai.vercel.app

## Overview
MediAI is an AI-powered health assistant designed to provide instant symptom analysis, wellness recommendations, medication guidance, and early care insights through an intuitive conversational interface.

## Features
- AI-powered symptom assessment
- Instant health guidance
- OTC medication suggestions
- Home remedy recommendations
- Emergency warning indicators
- Responsive modern UI
- Fast web-based access

## Tech Stack
- React
- Vite
- JavaScript
- Tailwind CSS
- Groq API
- Vercel

## Disclaimer
MediAI is intended for informational purposes only and does not provide medical diagnosis, treatment, or professional healthcare advice. Always consult a qualified medical professional.
